TWINSCAN lists every Solana coin that shares a name or ticker, side by side and oldest first, with the facts that tell them apart. Live from DexScreener.

Facts, not scores

  • Oldest pairIts first DexScreener pair was created before any other coin with this name.
  • Only one with a profile and linksNo other coin in the list has a DexScreener profile with a website or socials.
  • No profile and no linksDexScreener has no profile, image, website or socials for it.
  • Launched within 1 hour of the oldestIts first pair appeared less than 60 minutes after the oldest coin's.
  • Same links as #1It lists a website or social link that an older coin in the list already uses.

How it works

  1. Runs in your browser. It calls DexScreener's public API directly. No server, no tracking.
  2. Groups by exact match. Same name or same ticker, ignoring case, spaces, symbols and a leading $.
  3. Sorts by pair age. Oldest first, with how long after the oldest each twin appeared.
  4. Never asks for a wallet. There is nothing to connect or sign here.

$TWINSCAN is this project's ticker. The scanner is free for everyone and works the same whether you hold it or not.

TWINSCAN shows public DexScreener data. It cannot prove which coin the real team made. Not financial advice.
